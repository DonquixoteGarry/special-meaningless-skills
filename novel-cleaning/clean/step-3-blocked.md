## 步骤 3：屏蔽词清洗（Censor Word Cleaning）

### 3.1 显式屏蔽标记

搜索后的验证逻辑（代码中 `verify_quality`）：

```python
patterns = {
    '网址': re.compile(r'https?://|www\.\S+\.\w+|\.(?:com|net|org|cc|cn|tw)\b'),
    'HTML': re.compile(r'<[^>]+>|&\w+;|&\#\d+;'),
    '广告词': re.compile(
        r'笔趣阁|biqu\d{3}|更多精彩|本书来自|爱下电子书|速读谷|'
        r'飘天文|24K小说|严正声明|Txt,Epub,Mobi|qinkan|'
        r'章节内容开始|章节内容结束|蓝薬提醒|阅读更多小说最新章节'
    ),
    '页码': re.compile(r'^\d{2,4}$'),
}
```

另外注意：如果一行全是英文/符号（`re.match(r'^[A-Za-z0-9_ \'".,!?;:\-/@#$%&()]+$', stripped)`），跳过检查——这通常是正常的英文段落。

### 3.2 拼音替代屏蔽词

搜索已在规则文件 `encoding_fixes` 中但可能漏网的模式：

- `cāo` → 操
- `sāo` → 骚
- `sè` → 色
- 注意 `ad_patterns` 中已有的正则替换模式也会覆盖部分：
  - `(?<=[一-鿿])sè` → `色`
  - `(?<=[一-鿿])cāo` → `操`
  - `(?<=[一-鿿])sāo` → `骚`
  - `(?<=[一-鿿])i(?=[一-鿿])` → `日`

### 3.3 加规则后进入步骤 4

对步骤 2 和 3 中确定要修复的：
1. 追加到 `clean_novel_rules.json`
2. **必须**进入步骤 4 重跑清洗
3. 不能跳步直接手动修改文件
